Added an optional `name` field to `RateLimitRule` in BackendTrafficPolicy. When set, both local and global rate-limit rule keys use the provided name (e.g. `<policy-namespace>/<policy-name>/rule/<name>`) instead of the array index (e.g. `.../rule/0`), making rate-limit rule keys and metrics easier to identify and stable across rule reordering. Local rules can set `name` only when they have `clientSelectors`, because the selectorless rule configures the default bucket and has no descriptor key. Unset `name` preserves the existing index-based behavior.
