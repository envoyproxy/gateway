Added session persistence support to `GRPCRoute`. The `sessionPersistence` field on a GRPCRoute rule was previously accepted but ignored; it is now applied the same way as on `HTTPRoute`. Cookie-based (the default) and header-based persistence are supported, a session name is generated per rule when `sessionName` is omitted, and `absoluteTimeout` sets the cookie TTL when `cookieConfig.lifetimeType` is `Permanent`. A rule with an unknown persistence type is rejected with reason `UnsupportedValue`.
