Added `http3` to `BackendTrafficPolicy` and `Backend` cluster settings, enabling HTTP/3 to the backend. The default `Auto` mode uses HTTP/3 only for backends that advertise it through an `alt-svc` response header, racing a QUIC connection against a TCP one so it falls back to HTTP/1.1 or HTTP/2 when QUIC is unavailable, while `Always` sends every request over HTTP/3 without falling back. Because QUIC always runs over TLS, the backend must be configured with TLS through a BackendTLSPolicy or the Backend's `spec.tls`; a policy that enables `http3` for a plaintext backend is rejected with an `Accepted=False` condition.
