Strict Lua validation now enforces a fail-closed allowlist of filesystem paths and environment variables that Lua scripts may access during validation. By default the allowlist is empty, so all filesystem and environment variable access during validation is denied. To permit specific paths or environment variables, configure `EnvoyProxy.spec.lua.strictValidation.allowedPaths` and `allowedEnvVars`. A built-in set of sensitive paths (`/etc`, `/proc`, `/sys`, `/certs`, `/var/run/secrets`, `/run/secrets`) remains always denied and cannot be re-enabled through the allowlist. This only affects the `Strict` Lua validation mode; `InsecureSyntax` and `Disabled` are unchanged.
