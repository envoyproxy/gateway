Added a `serviceSettings` field under `EnvoyGateway.spec.rateLimit` to configure the Envoy cluster that connects the proxies to the global rate limit service, such as circuit breakers, timeouts and health checks. It reuses the `ClusterSettings` type, but its fields are supported on a best-effort basis: known-unsupported fields are rejected (see the API reference), and a field that doesn't apply to the rate limit service cluster may have no effect. The CRD schema defaults, OpenAPI constraints and CEL rules of `ClusterSettings` are applied when the config is loaded, so an invalid value is rejected at startup.
