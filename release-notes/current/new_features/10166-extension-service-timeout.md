Added a `timeout` field to the Extension Manager's `service`. It bounds each extension hook call, including the time spent waiting for the extension server to become reachable and any retries. Previously an unreachable extension server blocked xDS translation indefinitely, because hook calls had no deadline and `failOpen` only applies once a call returns an error. With `timeout` set, the call fails with `DEADLINE_EXCEEDED` and `failOpen` takes effect. Leaving `timeout` unset keeps the existing behavior.
