When `mergeGateways` is enabled, an `ExtensionServerPolicy` that targets a `Gateway` (or a Gateway listener via `sectionName`) is now rejected with `Accepted=False` and reason `Invalid` instead of being attached. With merged Gateways all Gateways of the class share one xDS resource tree, so such a policy was previously forwarded to the extension server's PostTranslation hook for every merged Gateway rather than only the targeted one. Update these policies to target the `GatewayClass` instead.
