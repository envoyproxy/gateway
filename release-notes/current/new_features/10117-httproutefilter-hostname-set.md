Added a `Set` hostname modifier to `HTTPRouteFilter`'s `urlRewrite`, which rewrites the Host header to a hostname you specify (Envoy's `host_rewrite_literal`). Unlike the `Header`, `Backend` and `PathRegex` modifiers, the value is fixed rather than derived from the request, so the filter can be attached to an individual `backendRef` and give each backend of a weighted rule its own Host header — for example splitting traffic across two origins that each expect to be addressed by their own hostname.
