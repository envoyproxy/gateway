Added an optional `rbac.aggregatedClusterRoles.enabled` flag to the gateway-helm chart that creates `view`, `edit` and `admin` ClusterRoles aggregating read access to all, and write access to the safe subset of, Gateway API and Envoy Gateway custom resources, so cluster operators can grant scoped access to human users or groups without hand writing custom RBAC. GatewayClass, ReferenceGrant, EnvoyProxy, EnvoyPatchPolicy, Backend and EnvoyExtensionPolicy remain read-only even through `edit`/`admin`, since writing to them carries privilege-escalation or cross-tenant risk documented in the project's threat model and extension docs.
