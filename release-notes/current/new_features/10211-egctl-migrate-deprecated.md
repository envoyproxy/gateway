Added the `egctl x migrate deprecated` command, which rewrites the deprecated API fields that are removed in v1.11 to their replacements in manifest files (`-f`) or prints the migrated resources from a cluster (`--from-cluster`), with a `--mode check-only` report for CI. Fields that can't be migrated automatically, such as telemetry `host`/`port` that isn't a Service DNS name, the EnvoyGateway configuration and resources managed by Helm, Argo CD or Flux, are reported as errors and left unchanged.
