Added support for BackendTrafficPolicy to target a Service, ServiceImport, or Backend directly, applying cluster-scoped settings wherever the backend resolves - a merged BackendCluster, or an inline per-backendRef destination for HTTPRoute/GRPCRoute/TCPRoute/UDPRoute/TLSRoute - with backend-targeted settings taking precedence over any Route-level BackendTrafficPolicy on the same destination (requires the `MergeBackends` EnvoyProxy feature).
