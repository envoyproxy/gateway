Added `http3` to `BackendTrafficPolicy`, enabling HTTP/3 to the backend. The default `Auto` mode uses HTTP/3 only for backends that advertise it through an `alt-svc` response header and falls back to TCP when QUIC is unavailable, while `Always` sends every request over HTTP/3. The backend must be configured with TLS through a BackendTLSPolicy or the Backend's `spec.tls`; where HTTP/3 cannot be used for a route, it is left off and the policy reports a `Warning` condition.
