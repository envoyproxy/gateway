Added local Wasm modules registered on EnvoyProxy.spec.wasmModules (source type Local with a path today; shape matches DynamicModule for future sources). When EnvoyExtensionPolicy.wasm[].code is omitted, wasm[].name is looked up in that list so Envoy can load the file without the control-plane fetch and cache path. HTTP and Image stay on wasm[].code. The unused ConfigMap enum value (never implemented) was removed.
