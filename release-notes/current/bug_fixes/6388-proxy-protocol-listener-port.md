Fixed backends receiving the shifted container port, such as 10443 instead of 443, as the destination port of upstream PROXY protocol headers. Envoy now treats connections to a listener whose port is shifted as received on the listener port, so `downstream_local_address` in access logs also shows the listener port. This requires an Envoy Proxy version with the `envoy.filters.listener.original_dst.local_port` filter state object.
