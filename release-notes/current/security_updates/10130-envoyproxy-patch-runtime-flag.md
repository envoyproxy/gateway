Added an `EnvoyProxyPatch` runtime flag to `EnvoyGateway`. EnvoyProxy Kubernetes resource `patch` fields can grant arbitrary access to resources applied by Envoy Gateway's more privileged ServiceAccount when EnvoyProxy is namespace-scoped and tenant-authored. The flag is enabled by default to preserve pre-existing behavior; multi-tenant clusters where tenants can author their own EnvoyProxy resources should disable it through `runtimeFlags.disabled`.
