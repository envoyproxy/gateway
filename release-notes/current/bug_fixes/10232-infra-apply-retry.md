Fixed the infrastructure runner never retrying a failed Envoy proxy create or update, which left a Gateway without its Service (`Programmed=False`) after a transient API server or admission webhook error until Envoy Gateway was restarted. Such errors are now retried with capped exponential backoff until the apply succeeds or fails with an error that is not transient, or a newer update, a delete or shutdown supersedes it. An Envoy Gateway replica that loses its leader lease now stops applying proxy infra, including these retries, so it cannot overwrite the infra applied by the new leader.
