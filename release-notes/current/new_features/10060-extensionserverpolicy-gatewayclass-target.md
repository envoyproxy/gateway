`ExtensionServerPolicy` can now target a `GatewayClass` (via `targetRefs` or `targetSelectors`) when `mergeGateways` is enabled, attaching the policy to every listener of the merged Gateways. Targeting a `GatewayClass` without `mergeGateways` now reports an `Accepted=False` status instead of being silently ignored. `sectionName` is not supported on a `GatewayClass` target, since Gateway API only defines it for kinds such as `Gateway`, and such a target is rejected as `Invalid`; target a `Gateway` with `sectionName` to select a listener.
