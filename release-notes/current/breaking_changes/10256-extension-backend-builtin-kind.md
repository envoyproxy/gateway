Extension manager `backendResources` can no longer include the backend kinds Envoy Gateway resolves itself (core `Service`, `multicluster.x-k8s.io/ServiceImport`, `gateway.envoyproxy.io/Backend`), and Envoy Gateway now fails to start with such a configuration. Because extension backends are matched by group and kind, listing one of these took over every backendRef of that kind in the cluster, skipping Envoy Gateway's own validation and endpoint resolution for them. Remove these entries from `backendResources`; extensions that need to adjust these backends should use the xDS translator hooks, such as the `Cluster` hook, instead.
