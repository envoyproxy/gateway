Removed the defaulting and accessor helpers from the `github.com/envoyproxy/gateway/api/v1alpha1` Go package, such as `DefaultEnvoyGateway`, `SetEnvoyGatewayDefaults`, `GetEnvoyProxyKubeProvider` and `GetTargetRefs`. They are controller logic, not part of the API, and now live in an internal package. The CRDs and their behavior are unchanged; only external Go code that called these helpers needs to inline the logic it relied on.
