Added an `oauth2` credential to the `credentialInjection` HTTPRouteFilter (`HTTPRouteFilter.spec.credentialInjection.credential.oauth2`), which retrieves an OAuth2 access token from an authorization server with the Client Credentials Grant flow and injects it into the `Authorization` header as a bearer token; `credential.valueRef` is now optional, and exactly one of `valueRef` or `oauth2` must be set.
