Fixed a change to one route's API key credentials forcing a listener update. The listener-level `api_key_auth` filter carried the credentials of the first route on the listener that used API key authentication, so adding or rotating a key on that route rewrote the listener, which made Envoy replace the filter chain and drain the superseded one, terminating long-lived requests on every route of that listener. The same change on any other route was a route-only update. The listener-level filter config is now empty.
