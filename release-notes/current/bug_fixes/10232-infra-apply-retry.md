Fixed the infrastructure runner never retrying a failed Envoy proxy create or update, which left a Gateway without its Service (`Programmed=False`) after a transient API server or admission webhook error until Envoy Gateway was restarted. Such errors are now retried with capped exponential backoff until the apply succeeds or fails with an error that is not transient, or a newer update, a delete or shutdown supersedes it. Envoy Gateway now also exits when its provider stops while it is running, for example because the replica lost its leader lease, instead of running on without a provider, so a former leader cannot overwrite the proxy infra applied by the new leader.
