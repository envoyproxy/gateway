Fixed invalid QUIC listeners and LDS NACKs when HTTP/3 and Proxy Protocol are configured together. Downstream Proxy Protocol settings apply only to TCP connections; HTTP/3 remains enabled and accepts QUIC connections without PROXY headers. TLS fingerprinting also applies only to TCP, preventing invalid QUIC listeners when JA3 or JA4 is enabled. QUIC wildcard filter chains now reject requests associated with client-validated HTTPS and TLS termination hostnames on the same socket, including malformed authorities with empty or nonnumeric ports, additional colons, or bracketed prefixes, while retaining HTTP/3 for unprotected hostnames. HTTP/3 UDP Service ports are also exposed when an HTTPS listener shares its port with a TLS listener processed first.
