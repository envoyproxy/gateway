Added a `serviceSettings` field under `EnvoyGateway.spec.rateLimit` to configure the Envoy cluster that connects the proxies to the global rate limit service, such as circuit breakers, timeouts and health checks. It reuses the `ClusterSettings` type, but not all of its fields apply to the rate limit service; see the API reference for the unsupported ones. The CRD schema defaults, OpenAPI constraints and CEL rules of `ClusterSettings` are applied when the config is loaded, so an invalid value is rejected at startup.
