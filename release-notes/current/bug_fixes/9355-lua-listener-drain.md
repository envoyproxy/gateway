Changing the script in a Lua `EnvoyExtensionPolicy` no longer drains the listener, and adding or removing a policy usually does not either. The Lua filter configuration is served over ECDS, which Envoy applies in place instead of rebuilding the listener. The listener is still rebuilt when a gateway gets its first Lua policy or loses its last one, or when the number of Lua policies stacked on a single route crosses a multiple of ten.
