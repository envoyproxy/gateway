Downstream ClientTrafficPolicy `proxyProtocol` and `enableProxyProtocol` settings apply only to TCP connections. UDP/QUIC connections do not require PROXY headers, including when `proxyProtocol.optional` is false. When HTTP/3 is enabled on a shared listener address and port, HTTPS filter chains and HTTP/3 advertisements remain available regardless of their Proxy Protocol settings. Deployments that require all traffic to pass through a PROXY-speaking proxy must disable HTTP/3 on all listeners sharing that address and port or restrict UDP access.
