Added the `spec.tls.overlappingTLSHandling` ClientTrafficPolicy field to control HTTP/2 handling on listeners with overlapping TLS configuration (GEP-3567). It accepts `DowngradeToHTTP1` (the default, preserving the existing ALPN downgrade) and `MisdirectedRequest`, which keeps HTTP/2 enabled and returns 421 Misdirected Request for requests coalesced onto a connection established for another hostname.
