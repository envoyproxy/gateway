Fixed a transient failure to load the OIDC HMAC secret at startup leaving the Wasm cache uninitialized until the controller restarted, which rejected every EnvoyExtensionPolicy with an HTTP or Image Wasm source with `wasm cache is not initialized`. The controller now retries with backoff (capped at 5s) and holds off translating resources until the Wasm cache has started. On Kubernetes and host deployments, the `envoy-oidc-hmac` secret must therefore be readable by the controller before any resource is translated; until then it logs `failed to start wasm cache, retrying`.
