Added an optional `objectSelector` label selector to `provider.kubernetes.watch`. It filters the namespaced resources Envoy Gateway watches and reconciles (Gateway, ListenerSet, the route kinds and the policy kinds) by object labels, composes as an AND filter with any namespace watch mode, and does not apply to GatewayClass, referenced resources or Envoy Gateway-managed infrastructure.

To let multiple Envoy Gateway instances share a single namespace, the shared control-plane resources (Deployment, Service, ServiceAccount, ConfigMap, the certgen Secrets, the xDS Service name, the topology-injector Webhook, the leader election lease and the rate limit infra: Deployment, Service, ServiceAccount, ConfigMap, HPA and PDB) are now scoped by a per-instance resource prefix. Set the new `resourcePrefix` value in the Helm chart (passed to the controller as `ENVOY_GATEWAY_RESOURCE_PREFIX`) to a unique value per release and give each instance a unique `gateway.controllerName` and a disjoint `watch.objectSelector`. When the prefix is empty (the default), all resource names keep their historic values and single-instance installs are unaffected.
