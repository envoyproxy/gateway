Fixed route translation panicking when a backendRef to an extension backend resource whose kind collides with a built-in one (for example `custom.example.io/Service`) was dispatched to the built-in Service resolver: extension backend resources are now always handed to the extension, and the Service/ServiceImport resolvers report `BackendNotFound` for a missing object. Extension manager `backendResources` can no longer include the built-in backend kinds (core `Service`, `multicluster.x-k8s.io/ServiceImport`, `gateway.envoyproxy.io/Backend`); such a configuration is now rejected at startup.
