The session name generated when a route rule omits `sessionPersistence.sessionName` now ends with a short hash of the route identity (for example `httproute-default-route-1-rule-0-1a2b3c4d`), so routes whose namespace and name flatten to the same string (such as `a-b/c` and `a/b-c`) no longer share a session cookie or header. Existing HTTPRoute sessions that rely on the generated name lose affinity once after upgrading; set `sessionName` explicitly to keep a stable name.
