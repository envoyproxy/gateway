Added a `requestBodyLimit` field to `BackendTrafficPolicy` that caps the request body size of a route with Envoy's `body_size_limit` filter. A request whose body is larger than `maxSize` is rejected with HTTP 413, from its `Content-Length` header when present or as soon as the streamed body passes the limit, without buffering the body; unlike `requestBuffer` with mode `BufferAndLimit` it costs no memory and keeps HTTP upgrades such as WebSocket enabled. Requires Envoy proxy v1.40 or later.
