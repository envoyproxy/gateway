Added a `grpcJSONTranscoder` field under `HTTPRouteFilter` that enables Envoy's gRPC-JSON transcoder, letting REST/JSON clients call gRPC backends. Reference it from an HTTPRoute rule with an `extensionRef` filter. The proto descriptor is referenced from a ConfigMap in the route's namespace and is validated at translation time, so a malformed or incomplete descriptor makes the rule return 500 with the reason on the route's `Accepted` condition, instead of a rejected listener. Descriptors must be generated with `protoc --include_imports`. When `services` is omitted, every service declared by the descriptor's own proto files is transcoded, excluding services from imported files. Because the filter attaches per route rule, there is no gateway-wide form: each HTTPRoute rule that should transcode needs its own `extensionRef`.
