Added extension hook call counts and durations as OTel span attributes on the `XdsTranslator.processHTTPListenerXdsTranslation` span (`extension.hook.route_call_count`, `extension.hook.route_duration_ms`, `extension.hook.vhost_call_count`, `extension.hook.vhost_duration_ms`) and the `XdsTranslator.notifyExtensionServerAboutListeners` span (`extension.hook.listener_call_count`, `extension.hook.listener_duration_ms`), enabling latency and call-count visibility for extension server hooks in distributed traces. When multiple extension servers are registered, call counts reflect the sum of all servers actually invoked and durations cover the total time across all of them.
