Fixed Route `status.parents` (HTTPRoute, GRPCRoute, TLSRoute, TCPRoute, UDPRoute) retaining a stale entry for a Gateway removed from `spec.parentRefs`. The status merge logic previously kept every old parent status entry that wasn't part of the current reconcile batch, unable to distinguish a parent still in `spec.parentRefs` but not yet re-processed from one genuinely removed by the user; it now drops entries whose `parentRef` is no longer present in `spec.parentRefs`.
