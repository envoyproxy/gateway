Added CEL admission validation rules to the EnvoyProxy CRD: a Host provider without `host` set, a patch type other than StrategicMerge or JSONMerge, and non-CIDR values in `loadBalancerSourceRanges` are now rejected at admission time instead of being admitted and reported through status. Clients or upgrade workflows that rely on creating such objects and reading back the status error must update the manifests before applying them.
