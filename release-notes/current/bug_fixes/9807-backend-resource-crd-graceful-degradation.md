Fixed the controller crash-looping when an extension manager's `backendResources` references a CRD that is not installed in the cluster (or the controller's ServiceAccount lacks `list`/`watch` RBAC on it). The `backendResources` watch is now skipped with a warning log if the CRD is missing, following the same pattern already used for `ServiceImport`, `Backend`, and other optional CRDs. The reconcile list path (`getExtensionBackendResources`) only suppresses errors that identify the missing-CRD / unauthorized-resource case (`NotFound` / `NoMatch`), so transient failures (timeouts, canceled contexts) are returned and retried instead of publishing an incomplete resource snapshot.
