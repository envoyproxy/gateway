Outside the Host infrastructure provider, Backends now reject `localhost.`, names ending in `.localhost` (with or without a trailing dot), `localhost.localdomain` (with or without a trailing dot), `ip6-localhost.`, and `ip6-loopback.`, which were previously accepted. Plain `localhost`, `ip6-localhost`, and `ip6-loopback` remain rejected. Update affected Backends to use the intended non-loopback hostname; Host infrastructure behavior is unchanged.
