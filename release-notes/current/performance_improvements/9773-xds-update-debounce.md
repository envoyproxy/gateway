Added an opt-in debounce for resource updates, configurable via the top-level `debounce` field in the EnvoyGateway config. When enabled, Envoy Gateway merges bursts of resource changes into a single translation instead of translating and pushing each change on its own, which bounds how often configuration is pushed to Envoy Proxy when resources are churning. A pending batch is flushed once no new change has arrived for `debounce.after` (default 100ms), or after `debounce.max` (default 10s) if changes keep arriving. Debouncing is disabled by default.
